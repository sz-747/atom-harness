What's new

Install with one prompt

26 Oct 2026
  • Paste one prompt into your coding agent: it installs Pi and Atom, builds the banner and reports each check.
  • INSTALL.md lists every step and the checks to run, for an agent or by hand.
  • A launch page, with a sample session and the setup prompt to copy.

First public release

23 Oct 2026
  • Atom's startup banner, and a tab title that shows whether it is idle, working or done.
  • A guard that asks before force pushes, pushes to main, hard resets and recursive deletes.
  • Subagents, and short workflow prompts: /plan, /verify, /wrapup.
  • A Windows launcher that starts Atom in the folder you run it from.
