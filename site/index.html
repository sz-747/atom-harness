Get Atom

Windows 10 or 11, Git and Node.js 22 or later (24 to run the tests). You also need an account or API key for at least one model provider that Pi supports.

Recommended · one prompt

Let your coding agent install it

Paste this into Claude Code, Codex or any agent that can run commands on your PC. It installs Pi, sets Atom up, builds the banner, and tells you what passed.

Install Atom on this Windows PC. Follow https://github.com/sz-747/atom-harness/blob/main/INSTALL.md step by step: check Git and Node.js, install the Pi coding agent, clone the repo, install dependencies and build the banner. Ask me before installing anything globally or changing PATH. Finish with the checks at the end of the guide and tell me what passed.

Or by hand

Four commands

npm install -g @earendil-works/pi-coding-agent
git clone https://github.com/sz-747/atom-harness.git
cd atom-harness; npm ci; npm run build
.\atom.cmd

Run atom.cmd from the project you want to work on.
