01

Built on Pi

Atom runs on the Pi coding agent and keeps its tools and project trust checks as they are. It only adds a few extensions on top, so a model's results stay easy to read and compare.

02

A calm screen

A dragon banner fitted to your terminal, then out of the way. The tab title shows whether the agent is idle, working, done or stopped on an error, so you can look away while it works.

03

A guard before damage

Pi has no permission system, so Atom adds one where it matters. Commands that force push, push to main, hard reset, discard changes or delete recursively ask you first. Say no and the model explains instead of retrying. /guard turns it off for a session.

04

Short workflows when you want them

/plan turns a task into a checkable plan before any edit. /verify checks every claim against evidence before the model says done. /wrapup records what should outlive the session. Optional subagents can scout, plan and review.

05

Starts where you are

A native Windows launcher opens Atom in the folder you run it from, with your arguments and exit code intact. Nothing in your PATH or execution policy has to change.

Get Atom

Windows 10 or 11, Git and Node.js 22 or later (24 to run the tests). You also need an account or API key for at least one model provider that Pi supports.

Or by hand

Four commands

npm install -g @earendil-works/pi-coding-agent
git clone https://github.com/sz-747/atom-harness.git
cd atom-harness; npm ci; npm run build
.\atom.cmd

Run atom.cmd from the project you want to work on.
